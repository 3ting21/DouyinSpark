# 抖音续火花 1.7.1

Windows 10/11 x64 本地工具。设置好好友、时间与文案后，**到点由程序自己完成「生成文案 → 打开抖音聊天页 → 找到会话 → 输入 → 发送」全流程**，不再需要你手动复制粘贴。

## 安装与启动

1. 解压 `DouyinSpark_1.7.0_Windows_x64.zip`，双击 `DouyinSpark.exe`。便携版，无需安装 Python。
2. 点右侧「打开自动化浏览器（扫码登录）」，在弹出的 Edge 窗口里用抖音 App 扫一次码。登录态保存在本机独立浏览器配置里，之后不用重复扫码。
3. 点「浏览器自检（不发送）」确认：登录态、搜索框、输入框三项是否可用。自检会在 `%LOCALAPPDATA%\DouyinSpark\shots` 留一张截图，便于排查页面改版。
4. 「新增好友」填写昵称、每日时间点、模板文案、可选表情图片，并勾选提醒授权。
5. 打开「自动化与 AI 设置」：开启「到点自动发送」；如需每次文案不重样，填自己的 API Key（智谱 GLM / DeepSeek / 任意 OpenAI 兼容端点），不填则使用模板文案。想用 AI 画表情，再把「图像模型」填上（智谱选 `cogview-3-flash` 即可）。
6. 每位好友**第一次**被自动发送前会弹一次确认（可勾选「以后都自动发送」），确认后不再打扰。

## 全自动流程

| 阶段 | 程序行为 |
| --- | --- |
| 到点 | 调度器判定该好友该时间点到期，占用当日次数并进入发送队列 |
| 文案 | 开启 AI 时调用模型生成一条短消息；失败/超时/未配置 Key 自动回退到该时间点的模板文案。时间点选「只发表情」时跳过文案生成 |
| 定位 | 打开抖音聊天页 → 左栏按昵称做归一化模糊匹配（表情、空格、省略号自动忽略），多个同等相似的会话直接放弃，绝不猜测 |
| 发送 | 校验会话标题与昵称一致后写入输入框，回车发送；回车无效才点「发送」按钮 |
| 表情 | 每个时间点可选「只发文字 / 只发表情 / 文字 + 表情」。图片贴纸（PNG/JPG/GIF）单独走文件上传，unicode 表情作为文字发送 |
| 校验 | 发送后以消息列表新增为准；仅发表情时确认图片上传完成（弹窗「发送（1）」）后才关闭浏览器 |
| 失败 | 每位好友可配重试次数；仍失败则记录原因并弹窗提示，可手动补发 |

## 功能

- 每位好友可设置多个每日时间点、独立模板、表情图片和每日发送上限。
- 好友卡片上直接勾选「启用」即可开关该好友，不必进入编辑窗口；工具栏「批量启用」支持单选一位或多选统一启用/停用。
- 「今日续火花」面板（侧边栏或右侧「自动发送」卡进入）：按好友列出今日计划、已发条数、最近发送时间与每个时间点的「已发 / 待发 / 未发 / 失败 / 停用」，可只看今日未续、一键补发一轮。
- 编辑好友窗口为卡片化布局：基本信息 / 发送内容（每个时间点一张卡）/ 表情库，整页可滚动；文字与表情互相独立，可以各自单独发送。
- 首次确认后全自动；也可在设置里关掉自动发送，退回「提醒窗口 + 手动发送」。
- 独立浏览器配置目录（`%LOCALAPPDATA%\DouyinSpark\browser_data`），不读取你日常浏览器的登录凭据。
- 运行数据由 Windows DPAPI 加密保存在 `%LOCALAPPDATA%\DouyinSpark`，绑定当前 Windows 用户；支持导出加密备份。
- 浏览器自检、单好友测试发送、运行日志、参考配置导入、窄窗口自适应布局。
- 界面为「少边框、多图形」的卡片风格：好友卡用圆形字母头像 + 纯文字状态符号（● 已启用 / ○ 已暂停），不再套细边框和状态胶囊；侧栏是 Canvas 绘制的圆环 logo + 图标导航；五套主题（官方白、暖砂纸、深空蓝、石墨黑、曜石鎏金）在设置页一键切换。
- 滚动手感：鼠标滚轮在窗口任意位置都能滚动（好友列表、右侧面板、各弹窗），按住卡片空白处可拖动列表，PageUp / PageDown 翻页、Home / End 到顶到底。
- 好友搜索：按昵称、提醒时间（如 `12:`）或文案关键词实时过滤，标题旁显示匹配数量。
- 快捷键：Ctrl+N 新增好友、Ctrl+B 批量启用、Ctrl+E 今日续火花、Ctrl+F 搜索、F5 刷新，弹窗支持 Esc 关闭。
- 火花足迹：好友卡片显示「🔥 连续 N 天」；今日面板给每人画出「近 14 天」条纹（绿=已续、黄=跳过、红=漏发、灰=无计划），并标注已连续天数。
- 列表滚动后右下角出现「↑ 回到顶部」；双击好友卡片可折叠 / 展开详情；今日面板可一键「复制今天没续的名单」到剪贴板。
- 按抖音号找人：编辑好友里的「抖音号」支持 `abc123`、`@abc123` 或搜索链接；昵称和抖音号**至少填一个**，昵称太长记不住时只填抖音号也能保存，点「按抖音号找人」会在自动化浏览器里搜索用户并自动补昵称，长昵称不用手抄。
- 表情库：入口在编辑好友窗口「表情库」卡片右上角的「管理表情库（添加 / AI 生成）」；可以添加图片、从文件夹导入、删除，也能让 AI 直接画一张（需在设置里填图像模型）。
- 今天，听我的：右侧面板的暖色便签卡，显示带年份的日期与星期、每秒走动的实时时钟、按时段变化的强硬问候（起床别赖 / 吃饭别拿忙当借口 / 今天的事今天做完），以及一条加粗短句和作者；40 句本地池全是「现在，立刻，马上」「别装忙，做出结果」这类命令体；「盯你第 N 天」从第一次打开起累计；「换句更狠的」循环切换，「AI 也来一句」调用 GPT 兼容接口现场生成，右上角「复制」一键拷走。当天选的句子会存档，重开程序还是同一句，跨天自动换新，来源（本地 / AI）会标注出来。
- AI 文案：编辑好友时每个时间点都有「AI 候选」，一次给 3 条，点一条即填入；今日面板有「AI 本周小结」，按近 7 天漏发情况写复盘。
- 昵称模糊匹配：表情、全角/半角、空格、零宽字符、省略号截断都不影响匹配；左栏显示不全时按前缀判断；搜索浮层里的「联系人 + 发消息」卡片也能直接点进会话；相似到分不出来会停止发送，并在报错里列出左栏最接近的名字，方便改名。
- 接口排障：设置里「测试接口连通性」发一条 4 token 的 ping，显示 HTTP 状态 / 耗时毫秒 / 模型名；失败时指出是 Key、地址、模型名还是网络超时。「接口超时（秒）」默认 20 秒，中转慢就调到 45 秒以上；金句请求至少等 45 秒。
- 清晰度：启动时开启 Per-Monitor DPI 感知，Windows 缩放 125% 时字体按真实像素渲染，不再发虚。

## 使用限制与风险

- 需要本机安装 Microsoft Edge（Windows 10/11 默认自带）。程序用 Edge 的自动化通道工作，不打包第三方浏览器内核。
- 自动化浏览器必须是可见窗口：抖音对无头浏览器有风控，无头模式会被拦在登录页。
- 抖音网页版私信界面改版可能导致定位失败。程序遇到无法唯一确认的会话/输入框时会**放弃发送并记录原因**，不会盲发。
- 自动发送属于对平台页面的脚本操作，可能触及平台规则，存在账号风险；请只对明确同意的熟人使用，并把每日次数设低。
- 程序必须在运行且电脑处于唤醒状态；睡眠或退出时不会发送。
- 发布包未做代码签名，Windows SmartScreen 可能提示未知发布者；请核对随包 SHA-256。

## 校验下载文件

```powershell
Get-FileHash .\DouyinSpark.exe -Algorithm SHA256
```

结果应与 `SHA256SUMS.txt` 一致。

## 从源码构建

需要 Windows、Python 3.10+（含 Tk 与 Tcl 数据）以及能访问 PyPI 的网络。

```powershell
python -m venv .venv-build
.\.venv-build\Scripts\python.exe -m pip install "playwright==1.62.0" "pyinstaller==6.22.3"
$env:PYTHONPATH = "src"
.\.venv-build\Scripts\python.exe -m unittest discover -s tests -v
.\release.ps1 -Python .\.venv-build\Scripts\python.exe
```

打包后的 exe 支持无界面自检，用来确认 Playwright 驱动与 Edge 通道在冻结环境里可用：

```powershell
.\DouyinSpark.exe --selftest
Get-Content "$env:LOCALAPPDATA\DouyinSpark\selftest.json"
```

发布 ZIP 输出到 `release\DouyinSpark_1.7.1_Windows_x64.zip`。完整变更见 [CHANGELOG.md](CHANGELOG.md)。
